# AURELIA JEWELS

Free static earrings website for GitHub Pages.

## Edit products
Open `script.js` and change the product names/prices/images.

## WhatsApp
The order number is +91 97696 64319. To change it, replace `919769664319` in `index.html` and `script.js`.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload everything inside this folder, including the `images` folder.
3. Settings → Pages → Deploy from a branch → `main` → `/root` → Save.
